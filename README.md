## 📂 Projects

### 1. 🎙️ [Voice Assistant](./voice_assistant)
An AI-powered voice assistant built with Python featuring:
- **Neural Text-To-Speech**: Real-time voice responses using `edge-tts`.
- **Gemini AI Integration**: Intelligent general knowledge and conversational responses.
- **System Control & Automation**: Hardware status monitoring, web searching, weather updates, and reminder scheduling.

📁 **Folder Structure**:
- [`voice_assistant.py`](./voice_assistant/voice_assistant.py): Main application code.
- [`config.json`](./voice_assistant/config.json): Configuration file.
- [`requirements.txt`](./voice_assistant/requirements.txt): Dependencies.
- [`proofs/`](./voice_assistant/proofs/): Screenshots and execution proofs.
